# dhpay2 导出安全与大数据续跑

本次仅修改本地代码。服务器文件、Redis 数据、数据库和宝塔计划任务尚未变更。

## 安全与业务规则

- user、glht 商户 Download 入口继承 UserController，校验登录签名、会话期限、账号状态和登录随机串；管理员入口校验管理员会话，并沿用后台权限与谷歌验证。
- 提交只接受 POST 和会话 CSRF 令牌，21 个现有导出表单全部带令牌。
- 任务所有者来自已登录账号。商户可导出自己；选择其他商户时，数据库必须确认对方为当前账号的有效直属商户。任务保存所有者和被授权目标，两者不能由客户端任意替换。
- 商户导出币种取自本人或已授权直属商户的数据库记录；管理员可按币种筛选。币种仅接受三个大写字母。保留 dhpay2 的 balance、blockedbalance、currency 字段和代付原有列格式，账变直接按 currency 查询。
- 筛选字段和标量类型使用白名单，拒绝 ORM 表达式数组及路径类账号参数，合法状态 0 保留。必须提供完整的创建时间或成功时间范围，跨度不能超过 7 天。
- 新任务使用随机 ID 和 HMAC 签名，消费时再次验证。旧版无签名商户任务必须重新提交；旧管理员任务仍执行账号、类型、时间和筛选条件校验。
- 同账号未完成任务不限个数，无成功提交间隔；全局新提交等待队列最多 50 条。提交使用 Redis Lua 原子入队。

## 并发、续跑与资源

- open、api、glht worker 仅允许 CLI 调用，共用项目内 open/Runtime/export.lock；同一服务器同时只执行一个导出进程。跨服务器同时消费不受本机锁保护，需要另行设计分布式租约。
- Redis Lua 原子认领任务并加入运行队列。每批完整 CSV 落盘后保存进度；中断后下次持锁执行会恢复到最后完整分片，未完成分片重新生成。
- 代收、代付、账变、UTR 按每张表的 id 降序游标分页，每批最多 5000 行；不再先 COUNT 或使用深度 OFFSET。默认每轮 20 批或约 60 秒，随后排到队尾继续。
- 每个任务独立临时目录；最终仍提供单个 ZIP，其中包含多个带表头的 CSV。ZIP 完成后清理临时 CSV；归档完成、状态写回前中断时，可复用已完成 ZIP。
- PHP 内存上限 512 MB。单任务默认最多 2000 万行、临时 CSV 合计 10 GiB；硬上限分别 5000 万行和 50 GiB，最多 10000 分片。超过配额失败并清理临时文件，不能静默截断为成功。
- 每批及每轮保存 processed_rows，下载中心展示已处理行数，区分成功、无数据和失败。任务有效期与历史列表保留 7 天；进度更新刷新任务 TTL，任务创建时间超过 7 天仍会过期。
- 60 秒为批次边界的软预算，单条数据库查询或 ZIP 关闭可能超过预算。导出不是事务快照，执行期间更新或删除的记录仍可能改变结果。

## 参数

| 配置 | 默认值 | 可调范围 |
|---|---:|---:|
| EXPORT_MAX_ROWS | 20000000 | 1～50000000 |
| EXPORT_MAX_BYTES | 10737418240（10 GiB） | 1～53687091200（50 GiB） |
| EXPORT_BATCH_ROWS | 5000 | 1～5000 |
| EXPORT_SLICE_SECONDS | 60 | 10～300 |
| EXPORT_SLICE_BATCHES | 20 | 1～100 |

在三个 worker 应用中保持配置一致。调低每批行数会受 10000 分片上限影响。单 ZIP 归档时 CSV 与 ZIP 同时占用磁盘，至少按 CSV 配额两倍加余量规划空间，并计入已完成 ZIP 的存储；提高配额前用真实数据测量容量和数据库负载。

## 本地脚本与发布

1. 暂停旧 Export 调度，确认旧进程退出，备份现有代码和配置。
2. 同次更新 shared、三个 Download 入口、鉴权文件、三个 worker 及全部变更模板；shared 放在项目根目录，位于各站点文档根目录之外。
3. 四个应用现有 DATA_AUTH_KEY 已核对一致且长度足够，未修改密钥。若设置 EXPORT_TASK_SECRET，四个应用必须一致。
4. 确保 www 能读取 shared，并写入 open/Runtime、各 worker 的 Runtime/Temp 和 Uploads/download。只清理 ThinkPHP 编译模板缓存，保留日志、会话与业务文件，然后刷新导出页面。
5. 精确移除已确认恶意或失效的队列项，不清空整个 Redis。新签名任务不能交给旧 worker；回滚时继续停用导出提交和调度。
6. 在隔离环境验证真实 Redis 的 EVAL 权限、真实分表查询、查询索引、暂停续跑、崩溃恢复、ZIP 内容、多币种及代理权限，先小任务再千万行任务。
7. 宝塔执行用户设置 www，脚本使用实际部署目录：cd /实际路径/dhpay2/open && php cli.php Export。可以每 10～60 秒触发一次；程序内部锁会跳过重叠调度，不要加 sudo -u www 或在外层持有同一个锁。
8. api/shell/export.sh 已按自身路径定位项目，直接运行 open worker。api/shell/del_export.sh 只删除 open 下载目录内超过 7 天的成品 ZIP，不递归删除目录，不删除 .partial 或 Runtime 分片；脚本采用 LF 换行。其他 worker 的成品需按相同保留策略安排清理。

异常退出遗留的 Runtime 分片，只能在核对 Redis 任务无引用且未运行后清理；本次未增加自动删除规则。Redis 端口仅对必要主机开放，并监控队列长度、任务时长、CPU、内存、磁盘与失败数。

本地测试使用 PHP 7.4 和数据库/Redis 替身，不载入业务凭据、不连接生产服务；代码保持 PHP 7.2 语法兼容。本地验证不能代替服务器 PHP、真实 Redis、数据库以及千万行规模联调。
